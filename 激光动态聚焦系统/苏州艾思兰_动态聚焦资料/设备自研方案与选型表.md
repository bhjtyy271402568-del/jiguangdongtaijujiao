# 激光动态聚焦设备自研资料包

## 一、建议的第一版目标

建议先做“1064 nm 光纤激光器 + XY振镜 + Z动态聚焦模块 + F-Theta场镜”的3轴扫描头，面向曲面打标、深雕和小型曲面清洗验证。第一版目标建议：

- 扫描幅面：100×100 mm 或 200×200 mm；
- Z焦点范围：±20–40 mm（验证机），再扩展到±80 mm；
- 入射光束：6–8 mm，按场镜和振镜口径匹配；
- XY接口：优先 XY2-100；
- Z轴：闭环位置反馈或高刚性音圈/直线电机，配合编码器；
- 控制周期：至少1 kHz，目标与XY轨迹时间戳同步；
- 焦点重复性：先以±20–50 μm为工程验证指标，再向±10 μm级优化；
- 结构：光路模块、驱动模块、控制板、冷却模块分体，便于替换。

Sino-Galvo公开的FL8220-3D-500可作为性能上限参考：400–500 mm幅面、最大80 mm高度差、2000 mm/s标刻速度、XY2-100、重复定位精度小于8 μRad、8小时长期漂移小于0.5 mRad。该数据属于厂商规格，实际性能需要样机测试确认。

## 二、光机架构

### 方案A：前置动态聚焦（优先推荐做样机）

激光器 → 扩束/准直 → Z向移动透镜组 → X振镜 → Y振镜 → F-Theta场镜 → 工件。

优点是光路概念成熟、焦点连续可调，适合3D打标和曲面加工。关键难点是移动透镜的惯量、伺服带宽、透镜偏心、光束口径变化和Z轴与XY轨迹的同步。

### 方案B：三振镜/反射式动态聚焦

激光器 → 扩束 → 三个反射轴/特殊反射光学 → 场镜 → 工件。

优点是Z向响应快、适合大工作体积；缺点是光路、像差、光程差、标定和结构成本更高，适合作为第二阶段方案。

### 方案C：高度测量闭环

增加激光三角测量、共焦、白光或结构光传感器，实时测量工件高度并生成Z补偿。

这不是动态聚焦的光学替代，而是对曲面、翘曲和装夹误差的补偿层。需要处理传感器与加工光斑的空间偏置、采样延迟和遮挡。

## 四、控制软件最小功能

1. 导入DXF、SVG、点云或STL；
2. 将3D曲面转换为扫描轨迹；
3. 根据XY位置查询Z高度：Z=f(x,y)；
4. 对Z轨迹做前馈、限速、加速度和jerk限制；
5. XY、Z、激光功率和触发信号使用同一时间基准；
6. 支持镜头畸变校正、比例/零点校正和焦点偏置校正；
7. 记录实际位置、指令位置、温度、报警和加工结果；
8. 提供“静态焦点标定”“动态跟随标定”“功率-速度标定”三套流程。

## 五、建议的标定流程

### 1. XY几何标定

在平面标定板上打出网格，测量实际点位，拟合二阶或三阶畸变模型，生成查找表。验证四角、边缘和中心的定位误差。

### 2. Z焦点标定

固定XY位置，扫描多个Z位置，测量线宽、烧蚀深度或光斑尺寸，确定最佳焦点和焦点偏置；建立“Z指令—实际焦点位移”曲线。

### 3. 动态跟随标定

用阶跃、正弦和斜坡Z轨迹测试，记录跟踪误差、超调、相位延迟和重复性。Z轴动态性能应单独验收，不能用XY振镜速度代替。

### 4. 曲面加工验证

先做平面、球面、圆柱面和台阶面，再做真实工件；分别记录边缘光斑、线宽、深度和功率均匀性。

## 六、重点风险

- Z模块的机械响应通常低于XY振镜，轨迹速度过高会出现离焦；
- 场镜和动态透镜的组合必须重新做光学设计，不能只替换单个镜片；
- 光束口径、发散角和透镜行程变化会造成焦点尺寸和像差变化；
- 高功率下热透镜和结构热漂移会让静态标定失效；
- 传感器闭环如果没有补偿延迟，可能把曲面误差变成周期性焦点误差；
- 专利比对必须看权利要求，不应只看摘要或产品宣传。

## 八、建议研发顺序

1. 先买成熟XY振镜、场镜和控制卡，单独完成二维扫描；
2. 设计可更换的Z动态模块，先低功率验证焦点位移；
3. 完成Z轴静态精度、动态响应和温漂测试；
4. 做平面到球面/圆柱面的轨迹同步；
5. 再增加视觉/测距闭环；
6. 最后再考虑大幅面、三振镜或高功率版本。
