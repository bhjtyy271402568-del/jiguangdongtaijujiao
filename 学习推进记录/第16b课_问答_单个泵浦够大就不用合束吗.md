# 第 16b 课（问答）：915 单泵浦模块功率够大，就不用合束了吧？

日期：2026-11-11

**答：** 基本对。合束器的主要作用是把几路泵浦并成一路；只有一路时，可以不用多路合束器。

- **一路泵浦也得进到“内包层”里去。** 常见做法是端面泵浦：泵浦尾纤直接熔接到光纤一端，泵浦光进入内包层；那一端的光栅刻在纤芯里，泵浦光在包层里照样通过。小功率的光纤激光器（如几十瓦的打标机）常这么做，或者只用一两个泵浦。
- **为什么大功率机器还是用好几个泵浦 + 合束器：**
  1. **单个模块功率有上限**：芯片数、散热、尾纤粗细都有限。千瓦级激光器要一千多瓦泵浦，一个模块给不了（具体上限看厂家规格【估计】）。
  2. **“塞得进去”的限制**：功率越大，泵浦尾纤越粗、张角越大，内包层（如 400 μm）就接不下。分成几路，每路都细，才能都塞进去。
  3. **可靠和散热**：坏一个只少一部分功率；热量分散在几个盒子上。
  4. **成本**：中等功率的标准模块量大、便宜，几个凑起来往往比一个超大功率的划算。
- 和老师的项目无关：老师如果是直接用 915 打东西，就没有掺镱光纤和合束器这一套，泵浦模块本身就是激光器。
