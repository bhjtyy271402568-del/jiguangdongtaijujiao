# 第 10 课问答（再讲一遍，更基础）：磁铁、丝杆的缝、为什么选丝杆

> 2026-11-04。用户看完 3D 课件（第10d课）后说“还是没懂，你再讲清楚一点”。换成用户亲手碰过的东西讲，文字直接回答。

## 1. 磁铁有什么用
- **线圈通电 = 电磁铁**（继电器线圈一通电就吸铁片）
- 要推要拉，必须有**两块**磁铁（同极相斥、异极相吸）
- 音圈 = 线圈（通电变电磁铁，第一块）+ 固定的永磁铁（第二块）→ 互相推 → 线圈带镜片走
- 没有永磁铁 = 只有一块磁铁，没有对手；电流反向 = 电磁铁 N/S 对调 → 推变拉；电流大小 = 电磁铁强弱
- **喇叭**就是这样：背后是永磁铁，纸盆后面粘着线圈；拆掉磁铁就不响

## 2. 丝杆的“缝”
- 螺母拧在螺丝中间，不转、只沿轴向推拉，能晃一点点 → 这就是缝（牙比槽窄，不然拧不动）
- 数字【假设缝 0.05 mm，导程 1 mm，3200 步/圈】：换向要先转 1/20 圈（18°）= **160 个脉冲**，电机在转、镜片不动 → 控制里的**死区**，只在换向时出现
- 消隙螺母 = “双螺母防松”的思路：两个螺母各被顶向一边（一个贴左侧、一个贴右侧），中间用**弹簧**顶而不是拧死 → 还能转、又不晃

## 3. 为什么选丝杆不选齿轮（区别不在缝）
- **能不能被反推**：剪式千斤顶（丝杆）松开摇把车也不掉 = 自锁；自行车往后推脚蹬会转 = 能被反推。镜片要断电不跑 → 要千斤顶那种
- **一圈走多远**：千斤顶摇一圈只抬一点；汽车转向（齿轮齿条）方向盘一圈轮子打很多。20 齿小齿轮一圈约 31 mm，丝杆一圈 1 mm → 我们只走 4 mm、要准到微米 → 要细的
