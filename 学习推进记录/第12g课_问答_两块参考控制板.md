日期：2026-11-05

**用户：** 给了一个嘉立创 EDA 工程（STM32H7 + Tang 25K FPGA 开发板）和 GitHub 上的 pewpew-laserboard，“来两个你学习学习”。

完整对照写在控制卡仓库：`jiguang-zhenjing/参考设计/两块参考板对照_2026-11-05.md`。这里只记要点。

## 两块板各是什么

| 参考板 | 一句话 |
|---|---|
| A. STM32H750 + Tang 25K | MCU 和 FPGA 之间走 **FMC 16 位并口**（19 根线），FPGA 用可拆的核心板 |
| B. PewPew LaserBoard | 一块真在用的光纤打标控制板：XY2-100 振镜 + DB25 激光 + 4 轴步进，Teensy 4.1 |

## 学到的、落到我们项目上的

1. **FMC 并口**：FPGA 在 MCU 看来就是一段内存，带宽比 SPI 高一个数量级。我们首版还是用 SPI（够用），但草案里 PROGRAM_B / DONE 正好占了 FMC 数据线 PE7 / PE8，应该挪开，给以后升级留路。
2. **上电瞬间别误出光**：B 板 Rev5a 专门给激光输出加了下拉。Artix-7 的 PUDC_B 接低时，配置期间所有 IO 都上拉 → 要把 PUDC_B 接高，激光线按关光电平外部上下拉。
3. **门禁 / 急停只走硬件门**，FPGA 和 MCU 只读它。
4. **DB25 引脚草案对上了**主流 Raycus / JPT 定义；要补第 11 针（报警 / 地，跳线选）和第 17 针（Raycus 要 5 V，跳线）。
5. **出光时不能改重复频率**，否则可能出巨脉冲打坏镜片 → FPGA 只在关光时或周期边界更新频率。
6. **XY2-100 就是一路同步串口**（时钟 + 帧同步 + 数据），B 板直接用 I2S 外设生成。
7. **Z 调焦头的 STEP / DIR / EN / HOME 还没进控制卡引脚草案**。B 板的做法：5 V 缓冲输出；原点输入用 RC + 施密特 + 可选上下拉。

## 本课对项目的推进

- 控制卡引脚草案要改 4 处：
  - 挪开 PE7 / PE8；
  - PUDC_B 接高；
  - 加 Z 的 STEP / DIR / EN / HOME；
  - DB25 第 11、17 针。
- 新的待决定：首版 FPGA 直接画 BGA，还是先用 A35T 核心板。
