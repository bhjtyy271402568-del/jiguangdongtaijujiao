# 快速 06c（问答）：脉冲和连续（CW）的优劣势、使用场景

日期：2026-11-11 · 数值为【典型值 / 量级】

| | 脉冲（Pulsed） | 连续（CW） |
|---|---|---|
| 怎么出光 | 能量挤进极短的脉冲（ns 级），一秒几万下 | 一直出光，功率稳定 |
| 峰值功率 | 很高：平均 20 W，峰值约 10 kW | 等于平均功率 |
| 热影响 | 小：材料瞬间汽化，热来不及传开，边缘干净 | 大：热会传开，适合熔化、加热 |
| 精细程度 | 高，适合细线、表层加工 | 低一些，适合“大块”加工 |
| 平均功率 | 一般较小：打标 20–100 W，清洗可到 1–2 kW | 可以很大：几百瓦到几万瓦 |
| 速度（去除量） | 去除量小，适合表面 | 去除量大，适合切穿、熔透 |
| 每瓦价格 | 贵 | 便宜 |
| 控制 | 多一个重复频率（MOPA 还能调脉宽） | 只调功率和开关光 |

## 使用场景
- **脉冲**：打标（金属、塑料）、雕刻、激光清洗（除锈、除漆）、薄膜去除、微加工、打黑 / 彩色打标（MOPA）。
- **连续**：切割金属板、焊接（长缝、深熔）、熔覆、淬火、锡焊、加热。

## 一句话
要“表面干净、精细”选脉冲；要“切穿、焊透、加热”选连续。

## 和项目
远距离动态聚焦做什么活，决定选脉冲还是连续：远距离打标 / 清洗 → 脉冲光纤激光器；远距离加热 / 熔化 → 连续（半导体或连续光纤）。老师常见的 915 nm 半导体一般是连续的。这条也要和老师确认（打什么材料、做什么）。
