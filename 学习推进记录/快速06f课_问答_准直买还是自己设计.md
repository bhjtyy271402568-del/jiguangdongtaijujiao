# 快速 06f（问答）：准直要买模块，还是用 Zemax 自己设计？

日期：2026-11-11

**答：买。** 准直器是很成熟的标准件，自己设计不划算。

- **激光器自带准直的**（打标用脉冲光纤激光器，快速 06e）：连买都不用买。
- **不带的**（QBH / QD / SMA / FC 接头）：买对应接头的准直器模块。难点其实在机械：光纤端面要对准透镜焦点、对中、大功率时散热。这些模块已经解决好了，自己做反而费事。

**选准直器看几项：**
1. **接头**：和激光器输出接头一致（QBH、QD、SMA905、FC/APC……）；
2. **焦距 → 光束直径**：直径 ≈ 2 × 焦距 × NA（快速 02），按调焦头要的入口直径选焦距；
3. **镀膜**：对 1064 nm（或 915 nm）增透；
4. **功率**：额定功率够用，大功率要水冷；
5. **通光口径**：比光束粗一些，不挡光。

**Zemax 用在哪：** 不用来设计准直器，而是把买来的准直器当成“已知的入口”（厂家常给焦距或 Zemax 模型），用来设计我们自己的那一段——动镜 + 物镜的调焦扩束组，那才是要定制的部分。
