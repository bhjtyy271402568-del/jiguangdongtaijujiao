“0.07 个波长”是怎么算出来的

一张图，点“下一步”往下看。镜片和光线都放大画了；镜片的形状是按“每条光线光程一样长”真算出来的。

问题：RMS 波前 0.07 waves 是怎么算出来的？

自己玩：

记住一句：RMS 波前 = 各条光线到焦点的“路程差”（nm）取均方根、再除以一个波长；它就是几路光相位错开的程度，0.07 波长 ≈ 25°，几乎同相，所以合格。

本图对项目的推进：读 Codex 结果时，RMS 波前这个数 = 镜片让各路光“错相”多少；≤ 0.07 打勾。
示例数字（+80 / −60 / 0 / −60 / +80 nm）是为了好算编的；Zemax 用的是同样的算法，只是取几百到几千条光线。
