# 第 13h 课（问答）：相机那种凸轮筒更省钱吗？相机的音圈马达是带齿轮的那个电机吗？

日期：2026-11-06（2026-11-09 补记）

## 1. 凸轮筒省不省钱：要看做多少台
- **相机便宜，是因为量大**：凸轮筒、镜筒都是注塑或压铸件，一套模具摊到几百万台上，每台几块钱。
- **我们只做一两台，凸轮筒反而贵**：
  - 斜槽要在圆筒上加工成螺旋形，还要很精确，得用带旋转轴的数控机床，是定制件；
  - 齿轮还要消隙；
  - 镜筒在套筒里滑动有配合间隙，镜片会晃，远处会被放大（第 08 课：横向 1 μm 在 50 m 外变成 0.33 mm）。
- **丝杆方案几乎全是标准件**：丝杆 + 消隙螺母、微型导轨、步进电机都能直接买，只有支架要加工【估计：小批量时凸轮筒更贵，以报价为准】。
- **凸轮筒真正的好处是同轴、紧凑、对中好，不是便宜。** 等以后要做小、做量产，再考虑它（进度.md 待决定第 7 条）。

## 2. 相机的“音圈马达”不是带齿轮的那个电机
相机里常见的对焦电机有三类：

| 类型 | 怎么动镜片 | 有没有齿轮 / 凸轮筒 |
|---|---|---|
| 小直流电机 / 步进电机 | 小齿轮 → 大齿轮 → 转凸轮筒（用户照片里那种），或带丝杆 | 有 |
| 环形超声波马达（USM） | 一圈压电陶瓷环套在镜头里，直接转对焦环 / 凸轮筒 | 没有齿轮 |
| **音圈 / 线性马达**（手机、新款无反镜头） | 线圈装在镜片架上，在磁场里**直接推镜片沿导杆走**（第 10b、10d 课） | **都没有** |

所以，高端镜头宣传的“音圈 / 线性马达”恰恰是**不用齿轮、也不用凸轮筒**的直推方式；要有位置传感器，做闭环。驱动齿轮的是小直流电机或步进电机。
