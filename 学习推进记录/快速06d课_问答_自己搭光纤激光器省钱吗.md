# 快速 06d（问答）：想成本低，自己搞泵浦 + 光纤变 1064，再准直、前聚焦扩束，是最好的吗？

日期：2026-11-11

**答：后半段对，前半段不建议。**

## 光路这半段：对
准直 → 动镜 + 物镜（扩束兼调焦）→ 振镜 → 目标，也就是“前聚焦”（先聚焦、后拐弯）。这正是第 04 课定下、快速 06 讲的方案：远距离、大范围时，前聚焦最合适；短距离、小幅面时，用振镜后面加场镜的“后聚焦”更简单便宜。

## 激光器这半段：建议直接买，不要自己搭
自己搭一台掺镱光纤激光器，要的不只是泵浦和光纤：
- 双包层掺镱光纤、一对匹配的光栅、合束器 / 熔接、包层光剥离器、输出头、隔离器（防止反射光打坏激光器）；
- **工具**：光纤熔接机、切割刀、功率计、光谱仪，熔接机本身就很贵；
- **功夫**：熔接损耗、散热、反射保护、稳定性、光束质量都要调，做不好效率低、易烧。

而国产光纤激光器量大价低（几十瓦的脉冲打标源一般几千元量级【估计，以报价为准】），自己搭很难更便宜，还耽误时间。

**项目的自研价值在“控制卡 + 动态聚焦头”**，激光器当成买来的标准件：选一台带输出头 / 准直头的商用光纤激光器（远处要小光斑选单模），接上我们的调焦头和振镜。

## 例外
如果老师的课题本身就是**研究光纤激光器**（这时 915 nm 是泵浦），那就是另一个项目了，要自己搭。这也是要问老师的问题之一。

## 选型提醒
脉冲还是连续看干什么活（快速 06c）：远距离打标 / 清洗 → 脉冲光纤；加热 / 熔化 → 连续。
