# 快速 06b（问答）：QCW 和 CW 比有什么优劣？915 泵浦光纤一定出 1064 吗？常见 1064 都是 915 / 976 泵浦的吗？

日期：2026-11-11 · 数值为【典型值 / 量级】

## 1. QCW（准连续）vs CW（连续）
QCW 是把**泵浦电流本身**做成毫秒级的长脉冲（如 0.1–10 ms，占空比约 10%），峰值功率可以是平均功率的约 10 倍（如平均 150 W、峰值 1500 W）。

| | QCW | CW |
|---|---|---|
| 优势 | 用较小的平均功率得到高峰值：同样打一个焊点，比买 1500 W 连续机便宜；每个点的热输入可控；脉冲形状可编程 | 平均功率高、能一直出光，适合连续切割、长焊缝；结构和驱动简单 |
| 劣势 | 平均功率被占空比限死，干不了连续切割、高速长焊缝；毫秒脉冲仍是“热加工”，和纳秒脉冲（打标）不是一回事；驱动更复杂 | 想要高峰值就得买高功率整机；开关光调制时峰值也只是连续功率 |
| 典型用途 | 点焊（电池极耳）、打孔、精密焊 | 切割、焊接长缝、熔覆 |

## 2. 915 泵浦的光纤，出来的一定是 1064 吗？
不一定，**看光纤里掺的是什么**（掺的元素决定发什么光、吃什么泵浦）：

| 掺杂 | 常用泵浦 | 出光 | 用途 |
|---|---|---|---|
| 镱 Yb | 915 / 976 nm | 1030–1100 nm（1064 / 1070 / 1080） | 打标、切割、焊接（工业主力） |
| 铒 Er | 980 / 1480 nm | 约 1550 nm | 通信、测距、对人眼相对安全的波段 |
| 铒镱共掺 Er/Yb | 915 / 976 nm | 约 1550 nm | 镱吃泵浦再把能量交给铒 → **915 泵浦也能出 1550** |
| 铥 Tm | 793 nm 或 1.5 μm | 约 1.9–2.05 μm | 塑料加工、医疗 |

**不掺杂的光纤**没有增益（没有能被充电的离子），915 照进去就是 915 原样出来，只是一根传光的光纤；不会变成 1064。（例外：拉曼光纤激光器靠普通光纤的非线性把波长往长处“挪”一点，属于特殊用法。）

## 3. 市面上常见的 1064，一般都是 915 / 976 泵浦的吗？
- **光纤激光器（掺镱）**：是，基本都用 915 或 976 nm 半导体泵浦（大功率连续常用 976，915 吸收宽、温漂不敏感也很常见）。
- **固体激光器（Nd:YAG、Nd:YVO₄）**：也出 **1064 nm**，但泵浦是 **808 nm**（钕离子吃 808），老机器用闪光灯。很多紫外 / 绿光打标机就是 808 泵浦的 1064 固体激光器再倍频。
- 所以看到“1064 nm”，不一定是光纤激光器，要看是光纤还是固体。

## 和项目
老师要 915 nm，有三种可能：直接用 915 半导体打东西；做 / 研究掺镱光纤激光器（915 是泵浦）；铒镱共掺出 1550。三种对调焦头的要求完全不同，要问清楚。
