# 第 12h 课（问答）：Zemax 怎么用？Codex 为什么跑了好几种结构？

日期：2026-11-06

**用户：** Zemax 怎么用？Codex 给我跑了好几种结构。① 我不会操作；② 我看不懂为什么要这样设计。

## Zemax 在做什么
它是光学界的 SPICE。你把镜片告诉它：每个面弯多少、隔多远、什么玻璃。它从光源发出几百条光线，用折射定律一条一条算到目标上，然后告诉你这些光线落在哪里、挤得多紧（光斑）。

## 界面只需要认 4 样
| 东西 | 在哪 | 看什么 |
|---|---|---|
| 镜头数据表 Lens Data | 中间大表 | 一行一个面；一片镜子 = 两行（前表面、后表面）。几列：Radius 弯多少，Thickness 到下一面多远，Material 玻璃 |
| 多重结构 Multi-Configuration | Setup → Editors | 同一套镜片的几种状态 = 动镜停在 1 m / 2 m / … / 10 m 对应的位置 |
| 2D 光路图 Cross-Section | Analyze | 光线怎么走（最直观） |
| 点列图 Spot Diagram / 波前图 Wavefront Map | Analyze | 光斑多大，镜片打几分 |

另外还有**优化**：把某一格设成变量（选中格子按 Ctrl+Z，格子后面出现 V），再点 Optimize，Zemax 会自己调这个数，直到光斑最小。

## 为什么有好几种结构：这是我给 Codex 的任务单定的，每种回答一个问题
1. **理想透镜**：先用“没有误差的透镜”搭一遍，确认表填对了。相当于电路先用理想元件仿真。
2. **真实镜片：平凸 vs 双胶合**：真实的球面单片镜，边缘光线会折过头（叫“球差”），光斑因此变大。双胶合是两片不同玻璃粘在一起，误差互相抵消，但更贵。比较这两种，就知道值不值得多花钱。
3. **同一片镜子正反两种放法**：弯面朝平行光那一侧时，光在两个面上分摊着拐弯，每个面拐得少、误差就小。翻过来，像差可能差好几倍。
4. **短焦方案（f2 75 / f1 −15）**：为了解决行程不够（要 24.2 mm，现在只有 8 mm）。动镜行程跟 f2² 成正比，焦距减半，行程只剩约 1/4（5.5 mm），现结构就够用。代价是镜片更“猛”、像差更大，要用 Zemax 看能不能接受。

## 结果只看两个数
- **RMS 波前 ≤ 0.07 λ** = 镜片合格，光斑大小由激光器决定。
- **1–10 m 动镜行程** = 优化后间距的最大值减最小值，跟现结构的 8 mm 比。
