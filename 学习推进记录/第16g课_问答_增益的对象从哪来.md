# 第 16g 课（问答）：增益介质是放大器，那被放大的“对象”从哪来？

日期：2026-11-11

**用户：** 增益介质 = 放大器，泵浦 = 放大器的电源，那总要有个增益的对象吧？增益对象也是增益介质提供的？

**答：** 对，**被放大的就是光本身，而最初那一点光，正是增益介质自己发出来的**。
- 充了电的原子，有的会**自己掉下来**放出一个光子，方向随便（叫“自发辐射”）。这就像电路里的**噪声**。
- 绝大部分方向乱的光子跑掉了；碰巧沿着两面镜子方向走的那几个，被来回放大，越滚越大，最后成了激光。
- 这和电子振荡器一样：振荡器没有输入信号，靠的是电路自己的噪声起振，正反馈把某个频率挑出来放大。激光器也没有“输入”，靠自发辐射起振，两面镜子（光栅）把沿轴、对的波长挑出来放大。
- 对比：如果是**放大器**（比如 MOPA 的后级），被放大的光是**外面送进来的**（种子），它自己没有镜子、不起振。
