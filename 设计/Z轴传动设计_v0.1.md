# Z 轴传动设计 v0.1（对应结构 v0.4）

> 2026-11-04。尺寸唯一来源：`工具/结构参数.py`；模型：`CAD/调焦头_v0.4.step`；校核：`工具/Z轴传动计算结果.md`（16 项全过）；讲解课件：第 11 课。
> 【CAD】从模型算；【推算】脚本计算；【假设】典型值，选型后换成规格书数据。

## 1. 要求（从哪来）

| 要求 | 数值 | 来源 |
|---|---|---|
| 工作行程 | 4.05 mm（5 m ↔ 50 m） | 【推算】f2²(1/5 m − 1/50 m)，f2 = 150 |
| 定位精度 | 50 m 处 ±50 μm（越近越宽） | 【推算】需求落地计算.py |
| 速度 | 设一次距离，< 1 s | 【用户】距离由上位机设一次（第 05 课） |
| 断电 | 不能被推走 | 振动是最大误差（改进思路 v0.1）；第 10 课 |
| 接口 | STEP / DIR / EN / HOME | 远距离系统方案 v0.5 |

## 2. 传动链（从电机到镜片）

```
NEMA 11 步进 ─止口定心─ 电机座板
   └─ 波纹管联轴器 Ø12×12（吸收不同心，扭转无间隙）
        └─ 丝杠 Ø5 导程 1 mm
             ├─ 固定端：694 一对背靠背 + 锁紧螺母（前后推力都扛）
             ├─ 支撑端：694 一只，外圈可轴向滑（让热胀）
             └─ 消隙螺母：半螺母 A（固定）+ 弹簧 5 N + 半螺母 B（浮动）→ 回差 0
                  └─ 螺母支架 + Ø4 钢球 ─(拉簧保持贴紧)─ 滑块推板
                       └─ MGN7C 滑块（导轨 MGN7×55，垫高 8 mm）
                            └─ 镜座（台阶孔 + 螺纹压圈）→ 动镜 Ø12.7 f −30
```

| 设计点 | 为什么 | 参考 |
|---|---|---|
| 丝杠推、导轨扛 | 丝杠不受侧向力 | R010 |
| 固定—支撑轴承 | 两端都卡死时丝杠受热会被顶弯 | R010 轴承座；机床丝杠标准做法 |
| 消隙螺母 | 丝杠和螺母本来有缝，换向会空走 | R054 预紧思路 |
| 球头浮动接头 | 丝杠摆动不传给镜片；拉簧让接头也无间隙 | v0.3 浮动接头 → v0.4 |
| 波纹管联轴器 | 能弯不能扭 | R010 联轴器 |
| 原点在 5 m 端外 2 mm、限位在 50 m 端外 2 mm | 开关不会在工作区误触发 | CN120928524B |
| 硬限位 + 缓冲垫（工作区外 3.5 / 4.5 mm） | 开关失效的最后保护 | v0.3 |
| 运输锁 | 运输防颠；开机前拆 | R031 AGV3D |
| 遮光筒从 X = 138 开始 | 给支撑端轴承座让位 | v0.4 |

## 3. 校核结论（摘自 `工具/Z轴传动计算结果.md`）

- 运动部分 51 g【CAD】；推力 0.31 N；电机要 3.8 mN·m，可用约 30 mN·m【假设】，**安全系数 8**
- 一步 0.31 μm；全程 0.45 s
- 自锁：螺旋角 4.0° < 摩擦角 5.9°（μ = 0.10【假设】）；导程 4 mm 时 23°，不自锁 → 不选
- 回差 0（预紧 5 N ≫ 0.31 N）；联轴器扭转 0.03 μm
- 临界转速 20 万 rpm、失稳力 1.4 万 N：远超需要
- 热：丝杠/底座差 1.6 μm（支撑端吸收）；动镜—物镜 28 μm（< ±50 μm，可用温度传感器补偿）

## 4. 相对 v0.3 修正的错误
1. 原点开关在 X = 81，挡光片走不到 → 移到 86.5（5 m 端外 2 mm），限位移到 100.5
2. 导轨从 X = 78 开始，滑块后退到硬限位时会探出导轨 → 导轨改为 70–125（MGN7 标准长 55）
3. 浮动接头在 v0.3 里只是一个占位圆柱 → 画成真实结构：钢球 + 拉簧（并让出运输锁位置）
