# Zemax 脚本（零基础从这里开始）

## 先认识界面（打开 OpticStudio 后看到的 4 块）

| 位置 | 叫什么 | 干什么 |
|---|---|---|
| 左侧竖栏 | System Explorer | 全局设置：孔径（光束多粗）、波长、单位 |
| 中间大表 | Lens Data（镜头数据） | **一行 = 一个面**，从光源一路往后排；厚度 = 这个面到下一个面的距离 |
| Setup → Editors | Multi-Configuration（多重结构） | 同一套镜片的几种“状态”，这里 = 动镜停在不同位置 |
| Analyze 选项卡 | 分析 | 点列图（光斑长什么样）、波前图（镜片好不好）、2D 光路图 |

## 第 1 步：一键搭出理想透镜模型

1. 装 Python 3（勾选 “Add to PATH”），然后在命令行运行 `pip install pythonnet`（只需一次）。
2. 在 OpticStudio 里点 **Programming → Interactive Extension**，弹出等待连接的窗口后不要关。
3. 在本文件夹打开命令行，运行 `python 第1步_理想透镜.py`。
4. 脚本运行时会打印每一步“在界面里的位置”。跑完后照着在界面上点一遍。
5. 再点 **Analyze → Cross-Section**（2D 光路图），然后在多重结构里切换配置，就能看到动镜在不同位置时光线怎么走。

**如果 Programming 选项卡是灰的**（许可证不支持 ZOS-API）：照 `../../Zemax建模起步_v0.1.md` 第 1 步手动填，一共 5 行表 + 2 行多重结构。
